📘 Documentação Técnica — Bloomholm®

Bloomholm® é um mini game web inspirado na categoria de games MMORPG®, porém com uma temática pacífica. O jogador coleta flores, troca por moedas e participa de minijogos de memória para obter chapéus.

🧱 Estrutura de Arquivos

  • index.html — Estrutura e layout geral.
  • index.css — Estilo visual e responsividade.
  • index.js — Lógica, renderização e interações do jogo.

📄 Estrutura HTML

A página é composta pelos seguintes blocos principais:

  • Header: exibe o nome do jogo e botão de configurações.
  • Canvas: área principal de renderização.
  • Painel lateral: inventário, log e minijogo.
  • Modais: configurações, comentários, manual e nome do jogador.

Layout Responsivo

A interface utiliza flexbox e adapta-se com @media (max-width: 900px) para reorganizar o painel lateral abaixo da área de jogo. Os botões direcionais aparecem apenas em dispositivos móveis.

⚙️ Lógica JavaScript

  • Renderização: O mapa é desenhado via Canvas API com blocos de 32px.
  • Movimentação: Controlada por teclas WASD ou setas, com detecção de colisão em bordas e obstáculos.
  • Coleta e Troca: O jogador coleta flores e as troca por moedas ao interagir com o mercador.
  • Minijogo: Cada tentativa custa 10 moedas. Ao vencer, o jogador ganha um chapéu e uma moeda extra.
  • Inventário: Exibe chapéus colecionados e permite alternar visualmente entre eles.
  • Logs: Cada evento do jogo é registrado na interface textual.

🧩 Modais

Os modais são implementados com display: flex e z-index: 50 para sobreposição. São utilizados para:

  • Solicitar o nome do jogador no início.
  • Exibir configurações.
  • Mostrar regras do jogo (manual).
  • Receber feedback dos jogadores.

📜 Funções-Chave

  • drawTile() — desenha o cenário base.
  • drawPlayer() e drawMerchant() — renderizam os personagens.
  • drawNames() — exibe o nome “Jogador” e “Mercador” acima dos sprites.
  • attemptPick() — coleta flores e faz a troca com o mercador.
  • handleMiniClick() — lógica do minijogo de sequência.
  • giveCosmetic() — adiciona chapéu ao inventário.

💡 Observações Técnicas

  • O canvas tem dimensões fixas de 640x480px.
  • O jogador não atravessa bordas nem obstáculos.
  • Os controles móveis usam eventos touchstart.
  • Todos os modais são fecháveis clicando fora de suas áreas.
